三、Stage 执行顺序对比
--------------------------------------------------------------------------------

  RAGPipeline (standalone):
    route → rewrite → pseudo_answer → prepare_retrieval
    → apply_permission → retrieve → filter_permission
    → rerank → compress → prompt → answer

  EnhancedRAGPipeline:
    route → preprocess_parallel ─┐
    (内部并行: rewrite │ pseudo)  ← ★ 并行化
                                 ┘
    → prepare_retrieval → apply_permission → retrieve → filter_permission
    → bm25_rescore    ← ★ 新增
    → auto_merge      ← ★ 新增
    → grade           ← ★ 新增
        ↓ 不通过 → _rewrite_and_prepare_retry → 回流到 retrieve（最多 N 次）
    → rerank → compress → prompt → answer

五、新增 stage_preprocess_parallel 实现细节
--------------------------------------------------------------------------------

  def stage_preprocess_parallel(self, context):
      if self.pipeline_mode == "fast" or context.get("stop_pipeline"):
          return context

      question = context["question"]

      with ThreadPoolExecutor(max_workers=2) as executor:
          future_rewrite = executor.submit(rewrite_question, question)
          future_pseudo  = executor.submit(generate_pseudo_answer, question)

          context["rewrite_result"]       = future_rewrite.result()
          context["pseudo_answer_result"] = future_pseudo.result()

      return context

  设计要点：
  - rewrite_question 和 generate_pseudo_answer 各自创建独立的
    OpenAICompatibleChatClient 实例，线程安全
  - ThreadPoolExecutor max_workers=2，两个调用同时发起
  - future.result() 会传播异常，与串行版行为一致
  - fast 模式或 stop_pipeline 时直接跳过，保持兼容


六、增强功能开关
--------------------------------------------------------------------------------

  EnhancedRAGPipeline.__init__ 新增参数：

  enable_bm25_rescore: bool = True     # 是否启用 BM25 持久化重打分
  enable_auto_merge: bool = True       # 是否启用父子层级自动合并
  enable_grade_rewrite: bool = True    # 是否启用相关性评估+回流
  grade_max_retry: int = 2             # Grade 不通过时最大重试次数
  auto_merge_threshold: int = 2        # 触发合并的子块命中数阈值
  auto_merge_max_steps: int = 2        # 合并最大步数
  bm25_state_path: str | Path = None   # BM25 状态文件路径

  所有增强功能均可独立关闭，关闭后行为退化到与 RAGPipeline 一致。
